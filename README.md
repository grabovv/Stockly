# 📦 Stockly

Stockly is a lightweight, browser-based inventory management application built with vanilla HTML, CSS, and JavaScript.

It allows you to manage products, track stock levels, upload product images, search and filter items, export/import data as JSON backups, and generate printable inventory reports.

All data is stored locally in the browser using LocalStorage, so no backend or database is required.

## ✨ Features

- ➕ Add, edit, and delete products
- 📊 Increase or decrease stock levels
- 🖼️ Upload product images
- 🔍 Search and filter products
- 🟢 Stock status indicators
- 💾 Export and import JSON backups
- 🧾 Generate printable inventory reports
- 📱 Responsive layout for desktop, tablet, and mobile
- 🗂️ Local data storage using LocalStorage

## 💾 Data Storage

Stockly does not use an external database.

All application data is stored locally in your browser using LocalStorage.

For this reason, it is recommended to regularly export a JSON backup, especially before clearing browser data.
